# 99 Names of Allah - Asma-ul-Husna 🌙

A beautiful, interactive website to read, learn, and reflect on the **99 Names of Allah (Asma-ul-Husna)**.  
Built with HTML, CSS, and JavaScript to combine coding with remembrance of Allah.

## ✨ Features
- **All 99 Names**: Arabic, Transliteration, and Meaning
- **Search & Filter**: Find any name instantly
- **Audio**: Listen to pronunciation of each name
- **Beautiful UI**: Calm, Islamic aesthetic with dark/light theme
- **Responsive**: Works perfectly on mobile, tablet, and desktop
- **Copy & Share**: Share your favorite name of Allah
- **Lightweight**: Pure HTML/CSS/JS - No frameworks

## 📖 What are Asma-ul-Husna?
Asma-ul-Husna are the 99 beautiful names of Allah.  
Each name reflects an attribute of Allah and reminds us of His mercy, power, and love.

**Example:**  
**Al-Rahman** - الرحمن - The Most Merciful  
**Al-Wadud** - الودود - The Most Loving  
**Al-Hafeez** - الحفيظ - The Protector

## 🚀 Tech Stack
- **HTML5** - Structure
- **CSS3** - Styling + Animations
- **JavaScript** - Search, Filter, Interactivity
- **Data**: JSON for all 99 names
- **No dependencies**
